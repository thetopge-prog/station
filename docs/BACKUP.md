# النسخ الاحتياطي

## نسخة الآن

```bash
npm run backup
```

تكتب ملفاً مضغوطاً في `.backups/` يحوي **كل جدول وكل سجل** في قاعدة البيانات.
النسخة الحالية ١٠ كيلوبايت تقريباً — أي أنها لحظية فعلاً، لا تستغرق ثانية.

النسخة تُؤخذ داخل معاملة واحدة (`repeatable read`)، أي أنها صورة واحدة متّسقة
للقاعدة كلها. بدون ذلك قد تلتقط النسخة طلباً كُتبت أصنافه بعد لحظة، فتُسترجع
فاتورة فارغة.

## استرجاع

```bash
npm run backup -- --list                                  ما لديك من نسخ
npm run backup -- --restore .backups/station-....json.gz  استرجاع كامل
npm run backup -- --restore .backups/station-....json.gz --only orders
```

`--only` هو الأهم عملياً: نادراً ما تريد إرجاع القاعدة كلها إلى الوراء. غالباً
حُذف شيء واحد بالخطأ، فتُرجع جدوله وحده وتبقى مبيعات اليوم كما هي.

الاسترجاع **كله أو لا شيء**: أي خطأ في المنتصف يُلغي العملية بالكامل، لأن قاعدة
مسترجعة نصفياً أسوأ من قاعدة معطوبة — لا أحد يعرف أي نصف هو الصحيح.

## التشغيل التلقائي كل ربع ساعة

على جهاز الهَب (الذي يعمل ٢٤ ساعة أصلاً)، شغّل هذا **مرة واحدة**:

```bash
schtasks /create /tn "Station Backup" /tr "cmd /c cd /d C:\Users\al3r1\OneDrive\Desktop\station\b && npm run backup" /sc minute /mo 15 /f
```

للإيقاف لاحقاً: `schtasks /delete /tn "Station Backup" /f`

## أين تُحفظ

المجلد الافتراضي `‎.backups/‎` داخل مجلد المشروع. ولأن المشروع داخل OneDrive،
فكل نسخة تُرفع تلقائياً إلى حسابك — نسخة ثانية خارج الجهاز بلا أي إعداد.

> إن كنت لا تريد أرقام هواتف الزبائن ومبيعاتك على OneDrive، اختر مجلداً خارجه:
> `npm run backup -- --out D:\station-backups`

للاحتفاظ بنسخة في مكان ثالث (فلاشة في الدرج مثلاً)، شغّل الأمر نفسه بمسارها.

## سياسة الاحتفاظ

- **كل نسخة** خلال آخر ٤٨ ساعة — هذه هي المدة التي يكتشف فيها أحدهم أنه حذف
  شيئاً بالخطأ.
- **نسخة واحدة يومياً** لمدة ٣٠ يوماً.
- ما هو أقدم يُحذف تلقائياً. الأقدم من شهر ليس نسخة احتياطية، بل سجل محاسبي —
  وهذا مكانه التقارير لا مجلد النسخ.

## ما لا تشمله النسخة

**صور المنتجات** (نحو ٧ ميغابايت في Storage). هي لا تتغيّر تقريباً، وأصولها
موجودة في مجلد `ADS/` وفي git. إن نقلت الاستضافة يوماً، انسخ الحاوية يدوياً أو
أعد تشغيل:

```bash
node scripts/import-product-photos.mjs ../ADS/A
```
